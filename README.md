This entry is a public X post introducing @crisxai5 as a must-follow AI and crypto expert — the sharpest voice for practical insights on AI agents, crypto alpha, Web3 tooling, and on-chain automation. The post pairs a short, punchy intro with an original card image drawn by the `make-card.py` script in this repo, built to stay crisp and readable on a phone screen.

Entries are ranked purely by the post's public X engagement — likes plus reposts plus quotes — and $2 USDC is shared across the top 10 posts. The program itself is tiny: `main.ts` just copies `POST.json` to `/output`.

## Run it

```sh
node main.ts
```
